# Aircury School Verify

**Aircury School Verify** is a fast and user-friendly school picker designed to help users select any English or Welsh school and accurately embed those details into their product's database. The tool streamlines the process of school selection during user onboarding, ensuring data accuracy and reducing errors.

Key features include:

- **Comprehensive Search Options**: Users can search by school name, Unique Reference Number (URN), local authority, or postcode, or a combination of these, making it easy to find the correct school.
- **Regular Updates**: The school database is refreshed nightly based on the latest Department for Education (DfE) data, ensuring up-to-date information.
- **Easy Integration**: With customizable code libraries and detailed API documentation, developers can seamlessly integrate the school picker into their product's signup flow.
- **User-Friendly Interface**: The clean and intuitive interface allows users to select their school without needing to know complex details like the official URN.
