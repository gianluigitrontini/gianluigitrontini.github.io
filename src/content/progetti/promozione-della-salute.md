# PromoSalute

**PromoSalute** is a digital health-promotion platform built to help citizens discover prevention initiatives, participate in local activities, and request health-promotion interventions in workplaces and schools.

The project consists of both a **web application and a mobile application**, sharing the same frontend codebase and requiring only minor platform-specific adaptations.

🌐 [promozionedellasalute.it](https://www.promozionedellasalute.it/home)

## My Role

I worked on the **entire frontend of the application**, from the public-facing experience to the internal management dashboard.

The frontend was designed to provide a consistent experience across **web and mobile**, using a shared Angular + Ionic codebase with only limited platform-specific splits.

## Technology

- **Angular** — main frontend framework
- **Ionic** — cross-platform UI and mobile application layer
- **Leaflet / OpenStreetMap** — interactive map and geographic visualization
- Responsive web UI
- Shared web + mobile codebase

## The Platform

PromoSalute connects citizens with health-promotion initiatives organized throughout the ASL territory.

Users can:

- Discover advice and recommendations for improving their health.
- Browse initiatives and projects available in their area.
- Find activities directly on an interactive map.
- Participate in public initiatives.
- Request health-promotion interventions for their workplace or school.

The platform also includes a **management dashboard** used to control and organize the projects and activities published on the platform.

## Custom Interactive Map

One of the most distinctive parts of the frontend is the **custom interactive map** used to visualize activities across the territory.

The map combines geographic data with the project's UI, allowing users to immediately understand where initiatives are located and explore them alongside the corresponding project cards.

It supports:

- Interactive geographic markers.
- Large numbers of activities displayed across the territory.
- Project/category visualization.
- Search by title or municipality.
- A synchronized list/map browsing experience.
- Direct access from an activity card to the corresponding project.
- Responsive behavior for different screen sizes.

The map was designed as an integrated part of the application rather than as a separate mapping page, making geographic discovery one of the primary ways of navigating the available initiatives.

## Project & Activity Management

Beyond the public-facing experience, I developed the frontend of the **management dashboard** used to control the platform's projects and activities.

The dashboard provides the tools needed to manage the content that appears throughout the application, creating a connection between the administrative side of the platform and the citizen-facing experience.

This required designing reusable interfaces and components capable of handling different types of information while maintaining a consistent UX across the application.

## Web + Mobile from One Codebase

A key architectural aspect of the project was the decision to build the web and mobile experiences around the **same Angular + Ionic frontend**.

Instead of maintaining two completely separate applications, the shared codebase allows the majority of the UI and application logic to be reused across platforms.

Platform-specific behavior is handled only where necessary, keeping the two experiences consistent while reducing duplication and maintenance overhead.

The combination of a highly visual geographic interface, a content-driven project system, and an administrative dashboard made the frontend considerably more than a simple informational website: it acts as the main interface between citizens, health-promotion initiatives, and the organizations managing them.
